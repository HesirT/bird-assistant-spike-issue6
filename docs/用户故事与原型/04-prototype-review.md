# 原型评阅与验证记录 v0.5

## 演示顺序

1. 首页选地点，展开不同人的观察，保存他人内容为书签。
2. 中央识别入口选择照片或声音，复核候选或保留待鉴定。
3. 保存私人记录，再单独加入收藏，对照外侧计数。
4. 同一私人记录分别发地图与论坛，只公开预览中的字段。
5. 更正私人原件，再查看旧的公开副本；分别撤回，原件应保留。
6. 切换评阅情景，检查权限、无候选、分析、保存与发布失败。
7. 查看好友、公开及区域收藏，编辑资料和检查缓存说明。
