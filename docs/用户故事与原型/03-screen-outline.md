# 原型页面与状态设计 v0.5

本表与可点击演示原型配套。页面编号保持稳定；编号间隙留给候选功能。页面入口存在不等于真实后端、识别与微信设备能力已经实现。

| 页面 | 名称 | 交互内容 | 对应故事 |
| --- | --- | --- | --- |
| P01 | 首页地图 | 搜索、日期和鸟种筛选，公开与私人标记，拖动、缩放、示例定位和选中状态。 | MAP-01、MAP-02、COL-03 |
| P02 | 地点观察底部面板 | 显示地点或聚合范围、观察记录数、日期排序和可打开的观察。 | MAP-02 |
| P03 | 观察详情 | 显示证据、观察时间、鉴定状态和公开署名；区分他人书签与自己的管理操作。 | MAP-02、REC-01、COL-04 |
| P04 | 收藏首页 | 我的、好友、公开、区域；个人鸟种格子、待鉴定组和独立的已保存入口。 | COL-01、COL-02、COL-03、USR-01 |
| P05 | 收藏详情 | 所有者或区域、可见范围或日期、记录和物种数量、每次观察的证据入口。 | COL-01、COL-02、COL-03 |
| P06 | 识别入口 | 中央大按钮；照片和声音流程；连续相机与视频明确为候选。 | ID-01、ID-02 |
| P07 | 照片输入 | 相机与相册分别进入，权限或格式失败时有替代入口。 | ID-01 |
| P08 | 照片预览 | 查看、更换、取消或分析照片；失败保留已选素材。主体选区仍是可选设计。 | ID-01 |
| P09 | 声音输入与回听 | 就绪、录制、停止、回听、重录和提交；使用明确标注的合成示例，不访问真实麦克风。 | ID-02 |
| P11 | 分析状态 | 处理中、取消、服务失败等状态；无可靠结果进入独立候选复核分支。 | ID-01、ID-02、REC-02 |
| P12 | 候选复核 | 排序示例候选、来源分数标签、P32 比较入口、手动更正和待鉴定，模型建议与用户选择分开。 | ID-01、ID-02、ID-04、REC-02 |
| P13 | 私人保存表单 | 实际观察时间、可选地点、备注和天气，以及独立收藏勾选；失败可保留重试。 | MAP-05、ID-04、REC-01、REC-02、COL-01 |
| P14 | 我的观察历史 | 私人记录、鉴定状态与所有者操作，区分观察时间和上传时间。 | REC-01、REC-02、COL-01、USR-01 |
| P15 | 地图发布预览 | 公开字段、实际观察时间、确认地点、署名或匿名，以及显式发布。 | MAP-04、MAP-05 |
| P16 | 位置确认 | 示例当前位置或拖动地图后确认；不把示意坐标当作真实 GPS 精度验证。 | MAP-03、MAP-04 |
| P17 | 讨论列表 | 帖子、作者、互动入口和直接写帖。 | COM-01、COM-02 |
| P18 | 帖子与回复 | 已公开内容和允许访问的附件，回复、点赞、书签、失败草稿。 | COM-01、COM-02、COL-04 |
| P19 | 帖子编辑 | 正文和可选观察附件，公开字段预览，草稿保留或丢弃和显式发布。 | COM-01 |
| P20 | 个人仪表盘 | 资料、明确口径的计数，以及历史、收藏、保存内容、好友和设置入口。 | USR-01 |
| P21 | 公开主页与好友入口 | 可见资料、被允许的收藏和关系状态，匿名内容不提供身份链接。 | COL-02、SOC-01 |
| P25 | 偏好设置 | 未来发布默认署名、权限说明、可见范围解释和缓存入口。 | USR-02 |
| P26 | 原件与发布管理 | 分别管理私人原件、地图副本和论坛帖子；单独更新和撤回。 | MAP-04、MAP-05、ID-04、COM-01 |
| P27 | 已保存内容 | 书签保留原作者与链接，原内容不可访问时显示失效提示。 | COL-04、COM-02 |
| P28 | 权限与缺失信息状态 | 解释不可用能力，保留手动地图、其他输入、重试或取消路径。 | MAP-01、MAP-03、ID-01、ID-02 |
| P29 | 好友申请状态 | 模拟申请、待回应、接受、婉拒和移除关系。 | SOC-01 |
| P30 | 编辑个人资料 | 显示名称与示例头像，校验、保存和取消。 | USR-01 |
| P31 | 缓存清理确认 | 区分可恢复预览与受保护原件，只模拟确认，不删除文件。 | USR-02 |
| P32 | 候选证据与来源比较 | 对照提交素材与有来源的鸟种特征，显示分数含义、来源可用/不可用/分歧和参考库资格；可返回选择、补充素材或保存待鉴定。 | ID-04 |

## 候选范围

P10 为短视频、P22 与 P23 为消息、P24 为徽章的保留编号。这些目前只有候选说明，不算 19 张正式讨论卡的可交互验收覆盖。连续相机另需完整状态设计。
