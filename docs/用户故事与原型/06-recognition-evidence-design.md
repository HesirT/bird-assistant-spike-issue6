# 候选与来源比较设计 v0.5

2026-10-23。中文为团队讨论稿，英文为对应副本。本修订扩展 ID-04，不改变 19 个故事的数量；增加 P32 后共 28 个设计页面/状态。

## 用户看到什么

1. 系统返回排序候选，用户查看具体来源和分数含义。
2. 用户进入“比较相似鸟种与参考来源”，对照自己的素材与参考特征。
3. 系统明确显示来源未接入、不可用或建议分歧，保留可用的已有结果。
4. 用户可以返回选择、手动更名、补充素材或保存为待鉴定。
5. 私人记录保留原始示例候选、分数和来源情景；用户更名不改写当时分析。

## 分数与证据

模型分数、图像/声音参考相似度和经验证的正确概率分别标注；不得把 0.78 自动显示为“78% 正确率”。不同来源的分数不直接平均，同一张照片在不同数据库转载不当作多份独立支持。参考物种特征不等于本次照片已经检测到该特征；缺少可观察证据时不得编造解释。

## 原型现在实际有什么

- 图像/声音候选及分数均为固定交互示例，没有对输入执行真实推理。
- P32 依据 Cornell Lab 的资料，人工整理了两种麻雀的文字对照，并附原文链接；未复制参考照片。
- 声音页明确合成示例不是候选鸟种的参考录音，不提供伪造的声学鉴别结果。
- 在线搜索/外部图库、社区参考库均未连接。来源分歧和不可用通过明确标注的评阅情景演示。
- 公开分享、允许作为参考样本、允许训练模型是分别决定的用途；未增加真实训练或用户素材复用。
- 真实图像参考库、分类名录对齐、来源去重、复核资格和模型训练另行实施，关联 REF-01 / DATA-01 与 Issue 5/6。

## 参考库建议规则

用户所选标签不自动变成正确答案。先区分用户选择、社区复核和合格参考样本，制定质量与授权条件；检索索引记录来源、版本与纠错/移出状态。检索复用与训练数据集分开；训练后的撤销影响不能用简单删除索引来冒充已经完成。
