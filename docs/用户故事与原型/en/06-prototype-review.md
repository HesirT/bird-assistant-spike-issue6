# Prototype review v0.5

The prototype opens in Chinese and has an English switch. It uses fictional places, sample illustrations, synthetic sample sound, simulated recognition and a demo identity. New data lives only in this session; refresh or reset clears it. Local gallery images stay in the browser and are not uploaded.

Browser checks covered independent private save/collection/map/forum flows, separate withdrawals, public snapshots after private edits, retryable save/post failures, failed sound analysis saved unresolved, no reliable candidates, denied permissions with alternatives, map search and grouping, regional filters, friend-only access, unavailable bookmarks, and language/draft retention. The accompanying Chinese log records individual results. Profile validation/save/cancel, friend requests/cancellation/removal, simulated cache confirmation and 414/360 px frame checks were completed. The real local file-picker path and native touch/phone/WeChat behaviour were not exercised.

This is an interaction demonstration, not a WeChat application or an AI/service benchmark. Device integration, real recognition, account/backend persistence, real messaging and native phone/touch validation remain outside the demonstrated functionality. Candidate video, continuous camera, conversations and badges have explanatory entries only.

The [Chinese review entry](../README.md) is in the parent folder. This English copy preserves matching story IDs and acceptance criteria for personal review. The overall course submission still needs the group's research, architecture, technology decisions and iteration plan. These materials are prepared for task-branch review; acceptance and merging remain team decisions.
