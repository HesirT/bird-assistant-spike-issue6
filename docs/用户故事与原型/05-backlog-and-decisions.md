# 候选功能与待定事项 v0.5

| ID | 候选能力 | 需要设计 | 依赖 |
| --- | --- | --- | --- |
| ID-03 | 短视频识别 | 素材预览、选取图像帧与声音、分歧候选和人工复核。 | 时长限制、抽帧、音画关联和小程序上传仍未验证。 |
| LIVE-01 | 连续相机辅助识别 | 检测叠加、稳定提示、拍摄和静态照片降级。 | 手机相机与推理链路未验证；检测与鸟种分类分别处理。 |
| SOC-02 | 私聊与群聊 | 会话列表、对话、成员和输入状态。 | 消息基础设施、群权限、通知与历史另行确定范围。 |
| BADGE-01 | 徽章与成长 | 徽章说明、获得状态及观鸟庭院候选：记录/学习、羽叶和装饰。 | 达成规则和统计口径须可解释；没有实际积分或游戏。 |
| WEATHER-01 | 自动观察天气 | 请求资料，显示来源/时刻，允许复核与修改。 | 历史天气可用性、费用和地点/时间匹配仍待调研。 |
| PHOTO-01 | 批量照片整理 | 导入、分组建议、代表照片选择与人工更正。 | 摄影桌面工具的做法须验证小程序文件与存储可行性。 |
| PLAN-01 | 行前规划与准备 | 地点比较、可用时间、路线与准备资料收藏。 | 团队愿景候选；真实需求、资料和路线能力仍需验证。 |
| OFFLINE-01 | 持久离线记录与同步 | 本地待上传队列、重试、同步和冲突状态。 | 需要持久存储和同步约定；本次会话草稿不等于离线同步。 |
| LEARN-01 | 学习与社区物种复核 | 参考比较、纠错建议和所有者复核步骤。 | 学习价值、可信参考资料和复核权限仍待定义。 |

收藏默认鸟种格子还是相册、地图初始范围、地点与区域边界、双向好友还是关注、公开副本更新规则、敏感位置策略、账号与媒体持久存储，均须在最终范围确认前讨论。

来源：用户 2026 年 10 月 22 日构想；仓库 README、第一次会议纪要、功能蓝图；Issue 3、4、6 和 PR 7；课程需求文档与原型设计截图。本轮核对的预研提交为 1b47109752fe91a31fa184c0dca04f706c504d31。
